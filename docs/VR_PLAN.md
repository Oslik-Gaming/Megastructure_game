# VR: разведка (фаза 0)

- Checkout `feature/vr-art-test`, Unity `6000.3.8f1`, URP 17.3. Уже есть OpenXR, XR Management, XRI 3.3.2, Input System, сэмплы Starter Assets и XR Interaction Simulator; проверять настройки PC/Android отдельно.
- `PlayerMovements`: Rigidbody с зафиксированным вращением, вертикальная капсула в `Body`, глобальная Y, ходьба/спринт/прыжок, звуки по текущим флагам. `PlayerHeadLook` поворачивает тело и `Body/HeadPoint`; игровая камера находится под головой. Камеру в VR лучше переиспользовать: её ссылки в HUD/хорроре останутся рабочими. XR Origin — дочерний объект физического игрока, не анимированной головы.
- `Assets/PlayerInputActions.inputactions`: `Movement`, `Sprint`, `Interact`, `HighlightTrash` (Q), `ToolPrimary`, `ToolSecondary`, `SelectTool1..4`, `Jump`, `Look`, `UI/PauseMenu`. Обёртку перегенерировать штатным импортёром. Текущие подписки инструментов сохранить; VR выбирает группу биндингов, не синтезирует клавиши/клики.
- `ToolController` / `ToolBobbing`: перенести весь `ToolAnchor` с существующими инструментами на калибруемый узел ведущей руки. Проверить `beamOrigin`, `heatZoneOrigin`; `PlayerRaycastInteract` сейчас использует общий `rayOrigin` для интеракта и захвата. `PaintSprayerTool` меняет запас краски, но не распыляет частицы, не делает рейкаст и не создаёт декали — подключать будущую реализацию к muzzle, не изобретать систему окрашивания в этой задаче.
- `CheckpointManager` и `DeathZone`: респавн на последнем чекпоинте через `ScreenFader`. Сохранить эту семантику и заменить VR-представление fade; проверить сохранения и время падения.
- HUD / crosshair / пауза / настройки используют UI Toolkit, не Canvas. Сохранить плоский UI; для VR нужен world-space HUD и отдельная навигация терминала с XRI. `EdgeGlitchEffect` работает с UIDocument, часть CRT/тумана — через Renderer Features. Для VR не использовать экранный CRT как есть.
- Три игровых ShaderLab (`ToolBeam`, `HeaterCone`, `TrashOutline`) проверить на SPI. `PC_Renderer`: fullscreen pass, туман AERO, SSAO; `CRT_Renderer`: отдельный fullscreen pass; `Mobile_Renderer`: без features. Для VR использовать чистый renderer, не менять desktop renderer. Стерео и стоимость fog/постобработки не предполагать по изображению Game View. Активной системы декалей грязи/краски не найдено.
- В этом checkout не найдены магнитная адгезия, шкала перегрева, перенос Ядра и поиск ближайшего неактивного робота. Вопрос: есть ли другая ветка с ними? Это не блокирует rig, существующий спринт, инструменты, UI и чекпоинты; не подменяем отсутствующие системы новыми правилами.
- Риски: наклоны гравитации и столкновения room-scale, переюстировка муцлов и видимость меша тела, привязка контроллеров к OpenXR interaction profiles, rebind/settings и тесты XR без шлема. Префаб/сцену создаёт меню Editor; существующий YAML не редактируется вручную.
