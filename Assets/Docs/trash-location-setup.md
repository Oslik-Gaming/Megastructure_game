# Настройка учёта мусора на локации

Система считает суммарный вес оставшегося мусора и передаёт процент в HUD.

## Структура локации

```text
Location
├── TrashRoot
│   ├── Trash_001
│   └── Trash_002
├── DisposeZone
```

## 1. Настройте локацию

1. Добавьте компонент `TrashLocation` на корневой объект `Location`.
2. Перетащите `TrashRoot` в поле `Trash Root`.
3. Оставьте `Collect On Awake` включённым.

Если поле `Trash Root` пустое, система будет искать мусор среди дочерних объектов `Location`.

## 2. Добавьте мусор

1. На каждый мусорный объект добавьте `TrashItem` (или наследников: `BigRock`, `Parasite`).
2. Укажите его `Weight`.

Вес влияет на процент: объект с весом `5` уменьшает процент в пять раз сильнее объекта с весом `1`.

### Обычный мусор (grabable)

Для объектов, которые должны падать в зону удаления, добавьте:

- `Collider`;
- `Rigidbody` с включённой гравитацией;
- `Grabable` (если игрок может подбирать и носить мусор).

### Специальный мусор (BigRock, Parasite)

Для неподвижного мусора, требующего инструменты:

- См. подробную настройку в `special-trash-and-tools-setup.md`;
- BigRock требует Destructor tool для разрушения;
- Parasite требует Heater tool для выжигания;
- Оба типа работают с TrashLocation и TrashDisposeZone автоматически.

## 3. Создайте зону удаления

1. Создайте объект, например `DisposeZone`, под картой или в мусорке.
2. Добавьте ему `Box Collider` и растяните до нужного размера.
3. Добавьте компонент `TrashDisposeZone`.

Компонент автоматически включает `Is Trigger` у Collider. Чтобы зона принимала только мусор конкретной локации, назначьте её в поле `Required Location`.

При попадании в зону мусор отмечается удалённым, процент пересчитывается, а объект уничтожается. Отключите `Destroy Game Object`, если объект должен остаться в сцене.
