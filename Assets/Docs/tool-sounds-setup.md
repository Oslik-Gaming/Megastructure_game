# Звуки инструментов и объектов

Документ описывает звуковую систему: универсальный компонент `ToolSoundPlayer` для инструментов и звуковые настройки предметов (`Grabable`, `TrashItem`, `Parasite`).

Все новые компоненты опциональны: если звуки не назначены, игра работает как раньше, без ошибок в консоли.

## Инструменты: ToolSoundPlayer

Компонент `ToolSoundPlayer` (`Scripts/Player/ToolSoundPlayer.cs`) вешается **на каждый объект инструмента** — рядом с `ToolBase`:

```text
ToolAnchor
├── ToolController
├── ToolSoundPlayer          ← для звука работы (цикл) и звука взаимодействия
├── GravityTool   (+ ToolBase)
├── PaintSprayerTool (+ ToolBase)
├── DestructorTool (+ ToolBase)
└── HeaterTool    (+ ToolBase)
```

Важно: у каждого инструмента должен быть свой `ToolSoundPlayer` и свой `AudioSource`, чтобы звуки не перебивали друг друга. Для 3D-позиции включите у `AudioSource` `Spatial Blend = 1`.

### Параметры

| Параметр | Описание |
|---|---|
| `Use Loop Sound` | Зацикленный **звук работы**. Играет, пока инструмент находится в состоянии «используется», и останавливается, когда оно прекращается. |
| `Use Loop Volume` | Громкость звука работы (0–1). |
| `Interact Sounds` | Список **разовых звуков взаимодействия** — играет случайный клип. У большинства инструментов — в момент начала использования. |
| `Interact Volume` | Громкость звука взаимодействия (0–1). |
| `Audio Source` | Источник звука. Пусто — берётся `AudioSource` с этого же объекта. |

### Как работает «звук работы»

`ToolSoundPlayer` сам следит за состоянием `ToolBase.State == Using`:

- **Тепловой конус (HeaterTool)**: конус работает **только пока удерживается ЛКМ** (`ToolPrimary`) и активен именно этот инструмент. Пока ЛКМ зажата и конус горит — состояние `Using` — гул луча играет; отпустили ЛКМ — звук останавливается.
- **Гравизахват (GravityTool)**: пока предмет удерживается (телекинез), инструмент принудительно держится в состоянии `Using` — значит, гул захвата играет всё время, пока объект летит за роботом. Когда предмет установлен или брошен — звук прекращается. Смена инструмента сбрасывает удержание (предмет падает) — звук останавливается вместе с ним.
- Остальные инструменты (деструктор, краскопульт) получают звук работы бесплатно: он привязан к состоянию `Using`.

Разовый `Interact Sounds` у гравизахвата дублирует «звук работы» (оба играют при начале использования). Если нужен только гул — оставьте `Interact Sounds` пустым; если нужен щелчок захвата — назначьте список, гул оставьте пустым.

## Звук сжигания паразита (Parasite)

В компоненте `Parasite` (`Scripts/Trash/Parasite.cs`) появился блок **Burn Sound**:

| Параметр | Описание |
|---|---|
| `Burn Sounds` | Список звуков сжигания. Играет случайный клип при каждом получении урона от нагревателя. |
| `Burn Sound Interval` | Минимальный интервал между звуками, сек (по умолчанию `0.4`). Урон идёт каждый кадр — интервал защищает от «захлёбывания». |
| `Burn Audio Source` | Источник звука. Пусто — берётся `AudioSource` с объекта; если и его нет — временный 3D-источник в точке паразита (громкость 1). |

Настройка:

1. Выделите объект паразита (или его корень с `Parasite`).
2. Добавьте `AudioSource`, назначьте клипы в `Burn Sounds`.
3. При желании ограничьте `Min Distance` / `Max Distance` для 3D-звука.

## Звук разрушения объектов (TrashItem и наследники)

В компоненте `TrashItem` (и наследниках `BigRock`, `Parasite`) появился блок **Removal Sound**:

| Параметр | Описание |
|---|---|
| `Removal Sounds` | Список звуков разрушения. Играет **случайный** клип при вызове `Remove()` — то есть при полном разрушении нагревателем, деструктором или при утилизации. |
| `Removal Audio Source` | Источник звука. Если пусто — звук играет как временный 3D-источник в точке объекта (`PlayClipAtPoint`, громкость 1) и не обрывается при удалении объекта. |

Внимание: `BigRock` и `Parasite` уничтожаются через 0.1 с после разрушения. Поэтому:

- **рекомендуется оставить `Removal Audio Source` пустым** — звук сыграет целиком в точке разрушения;
- назначать `AudioSource` имеет смысл, только если нужно управление громкостью, либо объект после разрушения не удаляется.

## Звук удара предмета о поверхность (Grabable)

В компоненте `Grabable` (`Scripts/Grabable.cs`) появился блок **Impact Sound**:

| Параметр | Описание |
|---|---|
| `Impact Sounds` | Список звуков удара. Играет **случайный** клип при столкновении предмета с чем-либо. |
| `Impact Min Speed` | Минимальная скорость столкновения (м/с), чтобы звук сыграл (по умолчанию `1`). Защищает от звука при лёгком касании и при медленной переноске. |
| `Impact Audio Source` | Источник звука. Пусто — берётся `AudioSource` с этого же объекта. |

Настройка:

1. На предмете с `Grabable` добавьте `AudioSource` (`Spatial Blend = 1`, `Play On Awake` — выкл).
2. Назначьте клипы в `Impact Sounds`.
3. Звук сработает и при ударе во время переноски, и при приземлении после броска, и при установке.

Если у предмета есть `ParasitePulse` с собственным `AudioSource` — используйте отдельный `AudioSource` для `Grabable` или назначьте тот же, звук не конфликтует (`PlayOneShot`).

## Быстрый чеклист

- [ ] На каждом инструменте: `ToolSoundPlayer` + свой `AudioSource`.
- [ ] Нагреватель: `Use Loop Sound` — гул луча; конус работает только на ЛКМ (так и было).
- [ ] Гравизахват: `Use Loop Sound` — гул удержания; звук играет, пока предмет в телекинезе.
- [ ] У паразитов: `Burn Sounds` в компоненте `Parasite`.
- [ ] У разрушаемых объектов: `Removal Sounds` в `TrashItem`/`BigRock`.
- [ ] У BigRock: `Stage Transition Sounds` — случайный звук при смене стадии разрушения.
- [ ] У предметов с `Grabable`: `Impact Sounds` + `AudioSource`.
