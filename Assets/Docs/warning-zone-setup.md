# Настройка зоны предупреждения

`HudWarningZone` задаёт разрешённую область. Когда игрок выходит из коллайдера-триггера, HUD показывает `CRITICAL WARNING` и переключает цвета с зелёного на красный. При возвращении цвета и предупреждение восстанавливаются.

## Настройка

1. Создайте пустой объект, например `Allowed Zone`.
2. Добавьте `Box Collider` (или другой Collider) и настройте его размер на разрешённую игровую область.
3. Добавьте `HudWarningZone`. Он сам включает `Is Trigger`.
4. Назначьте объект `GameHud` в поле `Hud`.
5. Компонент определяет игрока по `PlayerMovements`; у игрока должен быть Collider либо Rigidbody с Collider.

Не используйте эту зону для смерти: она только управляет визуальным предупреждением HUD.
