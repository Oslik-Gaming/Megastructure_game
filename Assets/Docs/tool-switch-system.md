# Система инструментов

Документ описывает настройку системы инструментов в сцене `ToolsTest.unity`.

## Иерархия

Инструменты должны находиться под `ToolAnchor`, который является дочерним объектом вертикально вращающегося `Eyes`:

```text
Player
└── HeadPoint
    └── Eyes
        ├── Camera
        └── ToolAnchor
            ├── GravityTool
            ├── PaintSprayerTool
            ├── DestructorTool
            └── HeaterTool
```

`ToolAnchor` следует за направлением взгляда. Каждый корневой объект инструмента должен содержать компонент `ToolBase`.

## Настройка ToolAnchor

На `ToolAnchor` добавьте:

- `ToolController`;
- `ToolBobbing`.

### ToolController

В поле `Tools` укажите ровно четыре компонента `ToolBase` в порядке клавиш:

| Элемент массива | Клавиша | Инструмент |
|---:|---:|---|
| 0 | `1` | GravityTool |
| 1 | `2` | PaintSprayerTool |
| 2 | `3` | DestructorTool |
| 3 | `4` | HeaterTool |

`Starting Tool Index` определяет инструмент, который будет активен при запуске:

- `0` — первый;
- `1` — второй;
- `2` — третий;
- `3` — четвёртый.

В Play Mode контроллер сам делает выбранный инструмент видимым, а остальные скрывает. Поэтому отдельная настройка начальной видимости у инструментов не требуется. В Edit Mode модели остаются видимыми для удобной настройки.

Во время переключения текущий инструмент проигрывает анимацию скрытия, затем новый инструмент — анимацию появления. Нажатия `1–4` во время этого процесса игнорируются. Повторный выбор уже активного инструмента также игнорируется.

### ToolBobbing

`ToolBobbing` покачивает только активный инструмент.

Основные параметры:

- `Walk Frequency` — частота покачивания при ходьбе;
- `Vertical Amplitude` — вертикальная амплитуда;
- `Horizontal Amplitude` — горизонтальная амплитуда;
- `Rotation Amplitude` — амплитуда поворота в градусах;
- `Sprint Multiplier` — множитель частоты и амплитуды при беге;
- `Return Speed` — скорость возврата в исходную позицию;
- `Movement Threshold` — минимальная горизонтальная скорость для включения покачивания.

Покачивание не работает во время переключения и в воздухе. При остановке инструмент плавно возвращается в исходное положение.

## Настройка каждого инструмента

### ToolBase

Добавьте `ToolBase` на корневой объект каждого инструмента.

Параметры:

- `Show Duration` — длительность появления;
- `Hide Duration` — длительность скрытия;
- `Hidden Local Position Offset` — смещение в скрытом положении;
- `Hidden Local Euler Offset` — поворот в скрытом положении.

`ToolBase` автоматически отключает дочерние `Renderer` и `Collider` у скрытого инструмента. Во время появления они включаются до начала анимации.

Начальную видимость через `ToolBase` настраивать не нужно: её определяет `ToolController`.

### GravityTool

На `GravityTool` добавьте компонент `GravityTool`.

Убедитесь, что компонент `ToolBase` этого объекта назначен в `ToolController → Tools[0]`.

Управление:

- ЛКМ — захватить объект или установить удерживаемый;
- ПКМ — бросить удерживаемый объект.

### PaintSprayerTool

На `PaintSprayerTool` добавьте компонент `PaintSprayerTool` и назначьте объект с компонентом `GameHud` в поле `Game Hud`.

Параметры:

- `Max Paint` — максимальный запас краски;
- `Initial Paint` — запас при старте;
- `Absorb Rate` — скорость восстановления при втягивании;
- `Spray Rate` — скорость расхода при распылении;
- параметры `Shake` — сила и частота вибрации при попытке распылять пустой краскопульт.

Управление:

- ЛКМ — втягивание жидкости;
- ПКМ — распыление краски.

Текущий запас хранится в `PaintSprayerTool`. HUD используется только для отображения через `GameHud.SetPaint(float)`.

### DestructorTool

На `DestructorTool` добавьте:

- `DestructorTool`;
- `LineRenderer` (можно несколько для многослойного эффекта).

Создайте дочерний объект `BeamOrigin` на конце сопла и направьте его локальную ось `Z` вдоль луча.

В `DestructorTool` назначьте:

- `Beam Origin` — `BeamOrigin`;
- `Beam Renderer` — `LineRenderer` на корневом объекте, либо оставьте поле пустым для автоматического поиска;
- `Beam Length` — максимальная длина луча, обычно `50`;
- `Beam Blocker Mask` — слои, блокирующие луч (должны включать окружение и `ToolTarget`);
- `Beam Damage Per Second` — урон BigRock в секунду (по умолчанию `25`).

В `LineRenderer` настройте:

- `Position Count` — `2`;
- `Use World Space` — включено;
- ширину, цвет, градиент и материал (для улучшенного визуала используйте `DestructorBeamBody.mat` или аналогичные).

**Функциональность:**
- ЛКМ показывает луч, пока удерживается
- Луч обрывается на первом препятствии из Beam Blocker Mask
- Наносит урон только BigRock объектам
- Камни разрушаются через стадии повреждения

Подробнее см. `special-trash-and-tools-setup.md`.

### HeaterTool

На `HeaterTool` добавьте компонент `HeaterTool`.

Рекомендуемая структура:

```text
HeaterTool
└── HeatZoneOrigin
    └── ConeVisual (HeaterConeVisual + MeshRenderer)
```

`HeatZoneOrigin` разместите у сопла и направьте локальную ось `Z` вперёд.

На `ConeVisual` добавьте:
- `HeaterConeVisual` — генерирует процедурный конус
- `MeshFilter` и `MeshRenderer` (добавляются автоматически)
- Материал `HeaterCone.mat` или аналогичный прозрачный

В `HeaterTool` назначьте:

- `Heat Zone Origin` — `HeatZoneOrigin`;
- `Cone Visual` — компонент `HeaterConeVisual`;
- `Cone Length` — длина конуса (по умолчанию `3`);
- `Cone Opening Angle` — угол раскрытия в градусах (по умолчанию `45°`);
- `Damage Per Second` — урон паразитам в секунду (по умолчанию `20`);
- `Distance Damage Multiplier` — кривая урона по расстоянию.

**Функциональность:**
- ЛКМ включает конус на время удержания
- Все Parasite внутри конуса получают урон одновременно
- Урон проходит сквозь стены (нет проверки line of sight)
- Паразиты уменьшаются и исчезают при нуле здоровья

Подробнее см. `special-trash-and-tools-setup.md`.

## Ввод

Действия находятся в карте `Player` файла `Assets/PlayerInputActions.inputactions`:

- `SelectTool1–SelectTool4` — клавиши `1–4`;
- `ToolPrimary` — ЛКМ;
- `ToolSecondary` — ПКМ.

После изменения `.inputactions` сгенерированный `PlayerInputActions.cs` нужно обновить через Unity. Вручную этот файл не редактируйте.

## Используемые скрипты

- `ToolController` — список инструментов, выбор по `1–4`, начальный инструмент и переключение;
- `ToolBase` — состояния инструмента, появление/скрытие, отключение Renderer и Collider;
- `ToolBobbing` — общее покачивание активного инструмента при ходьбе и беге;
- `GravityTool` — ввод гравизахвата;
- `PaintSprayerTool` — запас краски, втягивание, распыление и вибрация при пустом запасе;
- `DestructorTool` — луч с raycast, обрыв на препятствиях, урон BigRock;
- `HeaterTool` — процедурный конус, поиск Parasite внутри конуса, массовый урон;
- `HeaterConeVisual` — генерация mesh конуса для Heater;
- `PlayerRaycastInteract` — рейкаст, захват, установка и бросок объектов;
- `PlayerMovements` — состояния земли и бега, используемые bobbing-системой;
- `GameHud` — отображение запаса краски через `SetPaint`;
- `PlayerInputActions` — сгенерированный класс новой Input System;
- `TrashItem` — базовый класс для всех видов мусора;
- `DamageableTrashItem` — базовый класс для повреждаемого мусора с HP;
- `BigRock` — большой камень, разрушаемый через стадии;
- `Parasite` — паразит, уменьшающийся при уроне;
- `TrashPersistence` — сохранение состояния удаления мусора между сессиями.
