# Звук переключения инструментов

Документ описывает настройку компонента `ToolSwitchSound` (`Scripts/Player/ToolSwitchSound.cs`), который проигрывает звук при переключении активного инструмента.

## Назначение

Компонент следит за `ToolController` и при каждом **реальном переключении** активного инструмента проигрывает заданный клип. Стартовый инструмент, который контроллер выбирает при запуске сцены, звук не даёт — это не переключение.

Логика переключения (анимации скрытия/появления, клавиши `1–4`) остаётся в `ToolController` и не изменяется.

## Куда вешать

Компонент добавляется на тот же объект, где стоит `ToolController` (обычно `ToolAnchor`):

```text
ToolAnchor
├── ToolController
├── ToolSwitchSound     ← сюда
├── GravityTool
├── PaintSprayerTool
├── DestructorTool
└── HeaterTool
```

Если повесить компонент в другое место, укажите `ToolController` вручную в инспекторе — иначе в консоли появится ошибка `[ToolSwitchSound] Не найден ToolController`.

При добавлении компонента Unity автоматически добавит на объект `AudioSource` (задан через `RequireComponent`) — удалять его не нужно, звук играет именно через него.

## Параметры инспектора

| Параметр | Описание |
|---|---|
| `Tool Controller` | Наблюдаемый контроллер инструментов. Если пусто — берётся из родителей автоматически. |
| `Switch Sound` | Клип, который проигрывается при переключении инструмента. |
| `Volume` | Громкость звука переключения (от `0` до `1`). |

## Настройка звука

1. Добавьте `ToolSwitchSound` на `ToolAnchor` (рядом с `ToolController`).
2. В автоматически добавленном `AudioSource`:
   - `Play On Awake` — выключено;
   - `Loop` — выключено;
   - `Spatial Blend` — `0` (2D-звук), поскольку это звук интерфейса, а не источник в мире.
3. Перетащите клип в поле `Switch Sound` компонента.
4. При необходимости отрегулируйте `Volume`.

## Особенности поведения

- Звук играет через `PlayOneShot`, поэтому не прерывает другие звуки на том же `AudioSource`.
- Если клип не назначен, компонент просто ничего не играет — ошибок в консоли не будет.
- Повторное нажатие клавиши уже активного инструмента звук не даёт: `ToolController` игнорирует такой выбор.
- Отслеживание ведётся в `Update` по сравнению текущего и предыдущего активного инструмента, поэтому звук срабатывает в тот же кадр, когда контроллер начинает показ нового инструмента.
